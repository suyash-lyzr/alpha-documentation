Alpha is a workbench for building software with an AI agent. You describe the result in the chat; the agent writes the code, runs it on the session's own machine and shows it to you in a live **Preview**. When it looks right, **Publish** puts it on the internet at its own address.

## Every session has its own machine

Each session runs on an isolated cloud machine where the agent installs packages, starts servers and runs commands without touching any other session. Turns run on Alpha's servers, so work keeps going when you close the tab. After {idlePark} away, an idle machine sleeps; opening the session wakes it with every file as you left it.
