Alpha is a workspace for building software with an AI agent. You describe what you want in chat, and the agent writes the code, runs it and shows you the result while it works.

Every session runs on its own isolated machine, so the agent can install packages, start servers and run commands without touching anything else. Sessions pause when you leave and pick up where they stopped when you come back.

## What you get in a session

<CardGroup cols={2}>
  <Card title="Chat with the agent" icon="message">

  <Card title="Files, terminal and database" icon="folder-tree">
