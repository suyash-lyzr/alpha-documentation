Some limits are set by whoever runs your Alpha. Those are marked "(default)", and your Alpha may use a different value.

## Sessions and chat

{/* TODO confirm: the disk row; there is no product message for a full disk, so it describes ordinary system behaviour. */}

| Limit | Value | What happens when you hit it |
| --- | --- | --- |
| Idle time before a machine sleeps | {idlePark} | Once no Alpha tab of yours has been open for this long, each session with nothing running goes to sleep. Nothing is lost, and the machine wakes the next time you open the session or work arrives for it. |
| Length of one turn | {turnMax} | The turn is stopped. Your next message carries on from the conversation so far. |
| Disk per session's machine | {disk} | Writes inside the machine fail once the disk is full. Delete large files or build outputs to free space. |
| Length of one message | {promptMax} | The message is refused with "prompt too large". Attach long text as a file instead. |
| Repositories in a session | {reposMax} | You can't add another. A setup's repositories count toward this. |
| Size of one uploaded file | {uploadMax} | The upload is refused. |
| Image the agent can see | {imageMax} | Larger images are still uploaded to the session, but the agent gets them only as files, not as pictures it can look at. |
| Size of one file you download or view | {fileDownloadMax} | The download fails, and the file viewers say the file is more than they can fetch. |
| Size of a folder you download | {folderDownloadMax} | The download is refused. Dependency folders such as `node_modules` are always left out and don't count. |
| Length of one dictation | {dictationMax} | Recording stops by itself. Start the mic again to keep talking. |
| Queued messages | {queueMax} | You can't queue another until one has run. |

## Publishing

| Limit | Value | What happens when you hit it |
| --- | --- | --- |
| Published apps per session | {publishPerSession} | You can't publish another from this session. Republish an existing one instead. |
| Published apps per account | {publishPerAccount} | You can't publish another until you delete one. |
| Size of the source | {sourceMax} | Publishing stops with "workspace too large to deploy". Dependencies and build outputs are already left out, so look for large assets. |
| Build time | {buildMax} | The build is stopped and the version fails. Slim down the build. |
| Time for the app to start listening | {listenMax} | The version fails. Make sure the app binds `0.0.0.0` on the `PORT` it's given, and that its database is ready when it starts. |
| Memory per instance | {memory} | The app is stopped and the version fails with an out-of-memory message. |
| Instances at once | {instances} | Your app never runs more copies than this at the same time, however busy it gets. |
| Versions kept | {versionsKept} | The oldest versions and their logs are removed as new ones arrive. The version serving traffic is never removed. |

## Routines, setups and secrets

| Limit | Value | What happens when you hit it |
| --- | --- | --- |
| Routines | {routinesMax} | You can't create another until you remove one. Paused routines count. |
| Shortest gap between runs | {routineMinInterval} | A timetable that runs more often is refused, because each run wakes the session's machine. |
| Setups | {setupsMax} | You can't save another until you delete one. Setups shared with you don't count. |
| Number of secrets | {secretsMax} | You can't add another until you delete one. Your account's secrets and each session's own secrets are counted separately. |
| Total size of secrets | {secretsTotal} | The new value is refused because the total would be too large. |
